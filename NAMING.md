# Endorys naming standard

Effective: 26 October 2026. This implements the user's accepted naming proposal.

| Previous name | Current name | Purpose |
|---|---|---|
| JUPITER | **Endorys Platform** | Overall ultrasound-led multiphysics tissue research platform |
| KAVACHA | **Endorys Matrix** | Conformal geometry-aware sensing and interrogation surface |
| ANAVIXA | **Endorys Insight** | Acquisition-aware reconstruction, inference and response tracking |
| ASHWINI | **Endorys Interface** | Mechanical tissue interrogation, coupling, sensor interfaces and disposable components |
| CIELO | **Endorys Therapy** | Therapeutic acoustics and intervention research |
| SUSHRUTHA / SUSHRUTA | **Endorys Surgical** | Surgical and procedural tissue-awareness research |
| APOLLO | **Endorys Continuum** | Spatial-temporal tissue data, longitudinal memory and clinical integration |
| ATLAS | **Endorys Evidence** | Evidence, provenance, benchmarks and validation |
| COLUMBUS | **Endorys Explore** | Clinical discovery and materials/NDT exploration |
| JONWICK | **Endorys Bench** | Physical experiments and prototype testing |
| LUCIFER | **Endorys Challenge** | Critical review, falsification and failure analysis |
| VIA | **Endorys Vascular** | Vascular and procedural application programme |

## Rules

- Endorys is the umbrella identity. Endorys Platform is the full technical system.
- Use full branch names on first mention, followed by functional short names where clear.
- Vascular is an application programme, not the whole platform.
- Use lower-case functional slugs for folders and future repository names.
- Preserve exact historical titles, filenames, paths, URLs, correspondence and quotations when used as evidence.
- The common word Atlas in Endorys Explore Oncology Atlas is descriptive. It does not name the Evidence branch.
- Normalize both historical surgical spellings to Endorys Surgical in current prose.
- The physical surface previously illustrated as ANAVIXA Matrix is Endorys Matrix. The analysis engine is Endorys Insight.
- Interface retains both mechanical tissue interrogation and the later disposable-interface ecosystem. Continuum retains both integration and longitudinal data memory.
- Subbranch format: Endorys Explore / Clinical / Breast; Endorys Explore / Materials / Hydrogels; Endorys Therapy / Drug Delivery.

## Version and evidence

This is a naming revision, not a validated technical release or completion of the proposed v3.1 milestone. Hypotheses remain hypotheses. Earlier sources are retained for provenance.

Historical PDFs, PowerPoints and raster illustrations retain their embedded old names. They are legacy assets, not the current naming authority. The migration manifest tracks their pending visual rebranding.
