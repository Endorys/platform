# Security reporting

Endorys currently contains research documentation and a synthetic example, not a supported clinical deployment.

For suspected secrets, security vulnerabilities or accidental private-data exposure, contact sadhu.shobab@gmail.com with a minimal description and affected repository path/revision. Do not place credentials, identifiable patient records or exploit-sensitive details in a public issue. Do not send additional sensitive records as proof; first describe the concern.

No guaranteed response time, bounty programme or supported release window is established. There is no emergency medical support channel. Ordinary reproducibility problems can use a public issue after removing sensitive information.

Use only synthetic or appropriately authorized de-identified examples in public reports. A documentation fix or script check is not a safety certification.
