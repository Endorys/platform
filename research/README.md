# Endorys research library

Detailed research documentation, prepared 26 October 2026. Founder and concept originator: **Sadhu Shobab Bollipo**.

Endorys is an ultrasound-led multiphysics research platform. Its original breast motivation is preserved alongside other clinical and materials investigations. These pages distinguish proposals, external prior art, synthetic examples and evidence still required. No integrated physical or clinical performance is established here.

## Reproducible example

Run `python synthetic_acoustic_demo.py` using Python 3. It generates four synthetic waveform CSVs and a JSON summary in `synthetic_output/`, then checks toy timing and disconnected-signal behavior. These checks establish only that this deliberately simplified example runs as intended.
