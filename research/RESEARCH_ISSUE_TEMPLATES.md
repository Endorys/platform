# Issue drafting templates

These are copyable templates, not installed GitHub issue forms.

## Experiment proposal
Question; branch; evidence level; apparatus; reference/control; independent units; confounders; predefined criteria; data plan; hazards; required resources; decision enabled.

## Evidence correction
Claim; document location; current wording; primary source; what source actually supports; suggested correction; effect on downstream claims.

## Hardware/software fault
Revision; expected behavior; observed behavior; reproducible steps; non-sensitive logs/raw records; calibration; impact; workaround; proposed verification.

## Application opportunity
Intended user; exact decision; target population/specimen; existing comparator; measurable benefit; feasibility obstacles; evidence needed; stop criterion.
