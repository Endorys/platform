# Evidence-gated roadmap

All stages below are planned. Completion requires linked records; a diagram or code simulation does not close a physical gate.

| Gate | Work | Evidence required to advance |
|---|---|---|
| G0 | Freeze one measurable question and inventory | Intended measurement, comparator, available equipment, hazards and predefined criteria |
| G1 | Direct acoustic baseline | Raw traces, known geometry, instrument characterization and independent-session repeatability |
| G2 | Routing, contact and geometry | Path loss/dispersion, leakage, settling and contact/pose error budgets |
| G3 | One mechanical parameter | Calibrated load/displacement and model validity against a reference |
| G4 | One complementary modality | Registered measurements and improvement over ultrasound alone on held-out specimens/sessions |
| G5 | Identifiability and uncertainty | Confounder analysis, sensitivity limits, uncertainty calibration and rejection criteria |
| G6 | Reapplication and durability | Reseating/operator/session variability and documented failure modes |
| G7 | Biological feasibility | Appropriate oversight, specimen-specific controls and predefined feasibility endpoints |
| G8 | Specific clinical claim | Target population, intended use, reference standard and suitable clinical evaluation |
