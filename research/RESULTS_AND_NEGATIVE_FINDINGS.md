# Results and negative findings

As of 26 October 2026, this public documentation package contains no authenticated integrated Endorys physical dataset, clinical trial result or validated diagnostic performance estimate. Existing concept images are illustrations. The literature review concerns external work and does not establish Endorys performance.

The included executable example uses synthetic data only. Its self-checks verify the toy implementation, not tissue properties or hardware feasibility.

Future results should preserve unsuccessful and inconclusive runs, protocol deviations, missing data, calibration failures and alternative explanations. Use [the results template](RESULTS_TEMPLATE.md). Mark a result physical only when its raw data, apparatus, protocol and calibration can be inspected. Avoid replacing an earlier failure with a corrected result without retaining the correction history.
