# Contributing to Endorys

Endorys is founded and maintained by Sadhu Shobab Bollipo. Contributions should improve reproducibility, identify alternative explanations or clarify a specific application.

Open an issue describing the question, relevant branch, evidence level, source and proposed test. For a pull request, explain the change and validation, preserve citations and identify any generated or synthetic material. Report failures as carefully as successes. Include permissions and provenance for contributed code, data and images; do not contribute employer-confidential material or identifiable patient information.

No clinical claim should be added without appropriate supporting evidence. Discuss hardware changes with the maintainer before presenting them as canonical. Contributor acknowledgement does not automatically establish patent inventorship, ownership or clinical endorsement. Original software uses Apache-2.0 and original documentation uses CC BY 4.0; see [license scope](../LICENSE.md) and exclusions before reuse.
