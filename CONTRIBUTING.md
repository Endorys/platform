# Contributing

Thank you for helping make Endorys reproducible and scientifically useful.

## Before starting

Read [project status](docs/STATUS.md), [scope and limits](research/RESEARCH_SAFETY_AND_LIMITS.md) and [licensing status](research/LICENSING_STATUS.md). Original software uses Apache-2.0 and original documentation uses CC BY 4.0; read [license scope](LICENSE.md) for coverage and exclusions. Contributions to covered material should use the applicable license and identify any separate third-party terms.

## Workflow

1. Search existing [issues](https://github.com/Endorys/platform/issues).
2. Use an experiment-proposal, evidence-correction or reproducibility-report template.
3. For a substantive change, describe the question and acceptance evidence before implementation.
4. Make a focused pull request with changed files, rationale, provenance and verification.
5. Update relevant navigation and the changelog; preserve existing URLs where practical.
6. The maintainer reviews the evidence and scope before merge.

## Contribution standards

State whether content is proposed, synthetic, physically measured, biological or clinical. Include primary references near scientific claims. Preserve failed runs and alternative explanations. Generated images must remain labelled concepts. Never add fabricated measurements, affiliations, endorsements or certifications.

Use clear headings, relative links and one canonical source for each topic. Do not duplicate long protocols. For code, include a reproducible command, dependencies and meaningful checks. For measurements, include protocol, calibration, raw-data lineage and uncertainty.

Do not submit patient identifiers, confidential employer information, private correspondence or third-party designs without rights. Describe provenance and permissions for every contributed asset. Contact the maintainer before submitting material with unresolved ownership.

## Review checklist

- The problem and scope are clear.
- Evidence level and limitations are explicit.
- References, links and commands can be checked.
- Independent specimens/sessions are distinguished from repeated samples.
- New claims do not outrun supporting evidence.
- Sensitive information and secrets are absent.
